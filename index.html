태블릿 무대 사용 팁 & 단축키

  • 가사 터치 이동: 노래 중 반주와 어긋나면 원하는 가사 줄을 바로 터치하세요. 즉시 그 줄로 싱크가 점프합니다.
  • 별도 기기 반주 모드: 하단에서 ⏱ 별도 반주 (타이머)를 선택하면 태블릿 소리 없이 가사만 타이머로 흐릅니다. -0.5s / +0.5s / -2s / +2s 버튼으로 실시간 미세 조정이 가능합니다.
  • 정확한 싱크 맞추기: 상단 ⏱ 싱크 맞추기를 누른 뒤 반주를 틀고 각 줄이 시작할 때마다 화면(또는 스페이스바)을 탭하면 타임스탬프가 자동 저장됩니다.
  • 블루투스 페달 / 키보드:
    • Space : 재생 / 일시정지 (싱크 모드에서는 현재 줄 타임스탬프 기록)
    • ← / → 또는 PageUp / PageDown : 이전 줄 / 다음 줄로 즉시 이동
    • [ / ] : -0.5초 / +0.5초 싱크 미세 조정
    • R : 처음으로 이동 · F : 전체화면
  • 태블릿 앱처럼 설치: iPad Safari(공유 → 홈 화면에 추가) 또는 갤럭시 탭 Chrome(메뉴 → 앱 설치)으로 전체화면 PWA로 실행할 수 있습니다.
