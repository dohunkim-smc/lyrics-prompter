# Duet Lyrics Prompter

태블릿 화면에 가사를 띄워 두고 듀엣으로 노래할 수 있는 웹앱(PWA) 프롬프터입니다.

## 주요 기능
- **듀엣 파트 시각화**: Part A(노랑), Part B(하늘), 함께(초록) 색상 구분 및 **동시 가창 시 좌우 2단 스플릿 표시**
- **유튜브 반주 & 별도 반주(타이머) 듀얼 모드**: 태블릿에서 유튜브 반주를 직접 틀거나, 별도 스피커/PC/피아노 반주에 맞춰 타이머 모드로 가사만 진행
- **실시간 싱크 이동**: 원하는 가사 줄 터치 즉시 점프, `-2s / -0.5s / +0.5s / +2s` 미세 조정, 구간 빠른 이동(`전주`, `1절`, `듀엣` 등)
- **싱크 맞추기 (Tap-to-Sync)**: 반주를 틀고 각 줄이 시작할 때 화면(또는 `Space`)을 탭해 정확한 타임스탬프를 기록·저장
- **태블릿 무대 최적화**: 전체화면, 화면 꺼짐 방지(Wake Lock), 글자 크기 조절(`A-`/`A+`), 블루투스 페달/키보드 단축키, PWA 오프라인 지원

## 실행 방법

### 1) 같은 Wi-Fi의 태블릿에서 바로 열기
```bash
npx serve . -l 8080
# 또는 Python이 설치되어 있다면:
python -m http.server 8080
```
PC의 로컬 IP(예: `http://192.168.0.10:8080`)를 태블릿 브라우저에 입력해 접속합니다.

### 2) GitHub Pages로 배포해서 태블릿에 앱처럼 설치
저장소를 GitHub에 push한 뒤 `Settings → Pages → Branch: main`으로 활성화하면, HTTPS 주소로 접속해 iPad Safari(`공유 → 홈 화면에 추가`) 또는 갤럭시 탭 Chrome(`앱 설치`)으로 전체화면 PWA처럼 사용할 수 있습니다.
